Repositorio
Un repositorio es el lugar donde se almacenan los archivos y el historial de un proyecto.
Permite organizar el código, guardar cambios y trabajar de forma ordenada en el desarrollo de una aplicación o sitio web.

Commit
Un commit es un registro de cambios realizados en un proyecto dentro de Git.
Sirve para guardar una versión específica del trabajo con un mensaje que explique qué se modificó.

Push
Push es el comando que envía los cambios guardados en el repositorio local hacia un repositorio remoto como GitHub.
Esto permite actualizar el proyecto en línea y compartir los cambios con otras personas del equipo.
